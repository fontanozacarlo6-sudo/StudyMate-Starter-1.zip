StudyMate Starter

Files:
- index.html: main app page
- styles.css: visual design
- app.js: tasks and notes behavior
- manifest.json: installable app settings
- sw.js: basic offline cache
- icon.svg: app icon

To publish with GitHub Pages:
1. Upload all these files to the root of a GitHub repository.
2. Open repository Settings > Pages.
3. Under Build and deployment, choose Deploy from a branch.
4. Select main and /(root), then Save.

Task and note data is stored in the browser on this device only. It does not sync between devices.
